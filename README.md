# Lee English

**Live site:** https://leanhduc1989.github.io/Lee-English/

Free web app for learning everyday workplace English (HR, banking, real estate, energy), IELTS 6.0 level.

- One topic per day, rotating HR, banking, real estate and energy (12 lessons so far): listening with pictures (female voice, selectable), IELTS-style questions, transcript, new words, grammar, speaking role-play with the microphone.
- Progress is saved in each learner's browser. No account, no server, no AI costs.
- Works best in Safari (iPhone) and Chrome or Edge (computer).

Add a lesson: copy one block in `lessons.js`, change the content, and push.
